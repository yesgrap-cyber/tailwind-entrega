# Rueda Libre Medellín

Sitio web de un negocio de alquiler de bicicletas en Medellín. Muestra los servicios, las tarifas, los recorridos guiados y cómo reservar.

## Páginas

 **Inicio:** portada, quiénes somos, servicios, cómo alquilar y ubicación.
 **Tarifas y rutas:** precios de alquiler y recorridos guiados.
 **Reservas:** datos de contacto y horario de atención.

## Características

 Diseño responsive: se adapta a móvil, tablet y escritorio.
 Menú con submenús desplegables y botón hamburguesa en pantallas pequeñas.
 Tarjetas de servicios y tablas de tarifas que cambian según el tamaño de pantalla.
 Navegación entre las tres páginas y dentro del inicio.
 Uso de Tailwind.
